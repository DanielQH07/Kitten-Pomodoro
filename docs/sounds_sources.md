## 5. Xử lý bằng ffmpeg

```bash
# Cắt đoạn rồi chuẩn hoá âm lượng, xuất mono mp3
ffmpeg -ss 0.2 -t 1.3 -i in.wav -af "afade=t=in:d=0.02,afade=t=out:st=1.25:d=0.05,loudnorm=I=-18:TP=-2" -ac 1 -ar 44100 -q:a 4 meow1.mp3

# Làm "bịch" tiếp đất nhẹ như mèo: tăng cao độ ~ +30%, lọc thông thấp, nhỏ tiếng
ffmpeg -i land_in.wav -af "asetrate=57330,aresample=44100,lowpass=f=900,volume=0.5" -ac 1 -q:a 4 land.mp3

# Vòng lặp gừ gừ liền mạch (nối đuôi vào đầu bằng crossfade 1 giây, cắt tại giây 6)
ffmpeg -i purr_cut.wav -filter_complex "[0]atrim=0:6,asetpts=PTS-STARTPTS[a];[0]atrim=6,asetpts=PTS-STARTPTS[b];[b][a]acrossfade=d=1.0" -ac 1 -q:a 4 purr.mp3
```

Đặt file vào `extension/sounds/` (thư mục này bị gitignore). Tên file ở cột "File đề xuất" là tên mình sẽ dùng khi viết code nối âm thanh.

## 6. Về lời quảng cáo "gừ gừ giúp thư giãn"

Mình tìm thử: tần số 25–50Hz của tiếng gừ gừ là có thật, nhưng liên hệ với chữa lành hay giảm căng thẳng **chưa có nghiên cứu có kiểm chứng**, chủ yếu từ bài báo phổ thông. Trong mô tả app nên viết "nhiều người thấy dễ chịu", đừng ghi "đã được chứng minh".
